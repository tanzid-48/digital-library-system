# 📚 BookIfy - Digital Library System

A seamless and modern web application designed to digitize the traditional library experience. Users can explore a vast collection of books, filter by categories, and borrow titles digitally.

## 🌐 Live URL

🔗 [https://digital-library-system-five.vercel.app/](https://digital-library-system-five.vercel.app/)

## 📂 GitHub Repository

🔗 [https://github.com/tanzid-48/digital-library-system](https://github.com/tanzid-48/digital-library-system)

---

## 🎯 Purpose

BookIfy is an Online Book Borrowing Platform that allows users to:
- Explore a large collection of books
- Filter books by category
- Borrow books digitally
- Manage their personal profile

---

## ✨ Key Features

- 🔐 **Authentication** – Email/Password & Google Social Login powered by BetterAuth
- 📖 **All Books Page** – Search books by title and filter by category
- 📘 **Book Details Page** – View full details and borrow a book (Private Route)
- 👤 **My Profile** – View and update user information (Private Route)
- 🔄 **Trending Section** – Swiper.js powered trending books carousel
- 📢 **Marquee** – Scrolling new arrivals banner
- 📬 **Contact Section** – Send a message form
- 📱 **Fully Responsive** – Mobile, Tablet & Desktop
- 🔒 **Private Routes** – Protected with BetterAuth middleware
- 🌙 **Skeleton Loading** – Smooth loading experience

---

## 🛠️ Tech Stack

- **Next.js** – React framework
- **Tailwind CSS** – Utility-first styling
- **DaisyUI** – Component library
- **BetterAuth** – Authentication
- **MongoDB** – Database
- **Vercel** – Deployment

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/tanzid-48/digital-library-system

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

---

## 🔑 Environment Variables

Create a `.env.local` file in the root directory:

```env
MONGODB_URI=your_mongodb_uri
BETTER_AUTH_SECRET=your_better_auth_secret
BETTER_AUTH_URL=your_app_url
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```
